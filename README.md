# Extrator PFX - pagina de download

Pagina publica da CDN Tech para baixar as versoes portable do Extrator PFX.

Os executaveis sao distribuidos como arquivos de uma GitHub Release; este repositorio contem apenas a pagina de download. O programa processa certificados localmente, sem envio de PFX, senha ou chave privada para esta pagina.

## Publicacao

- Site: GitHub Pages a partir da raiz da branch `main`.
- Arquivos: GUI e CLI anexados a uma Release com tag `v1.5.0`.
- Links: `releases/latest/download/...`, para apontar automaticamente a release mais recente.
